# Backend skeletons

## Placeholders
| Placeholder | Meaning | Example |
|---|---|---|
| `<Entity>` / `<entity>` | class name / camelCase variable | `Supplier` / `supplier` |
| `<package>` | Java package | `supplier` |
| `<table>` | snake_case table | `supplier` |
| `<entities>` | URL segment | `suppliers` |
| `<Unique>` / `<unique>` | the unique field (class / camelCase) | `Email` / `email` |

Fields below are examples (`name` text, `email` unique text, `rating` optional Integer, `status` enum).
Replace them with the entity spec, keeping the same field order everywhere: SQL, entity, request, response, mapper, tests.

The package is `com.example.dealership.<package>`. Put each import group in the same order as `Vehicle*.java`.

## Migration: `V<n+1>__<table>.sql`
```sql
CREATE TABLE <table> (
    id     BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name   VARCHAR(100) NOT NULL,
    email  VARCHAR(100) NOT NULL,
    rating INTEGER,
    status VARCHAR(20)  NOT NULL,
    CONSTRAINT uq_<table>_email UNIQUE (email)
);
```
Seed (top-level only): `V<n+2>__<table>_seed.sql`.
- Provide 3 rows with realistic values.
- Emails go on `@example.test`.
- At least one optional column is `NULL`.
```sql
INSERT INTO <table> (name, email, rating, status) VALUES
    ('Northwind', 'orders@northwind.example.test', 5, 'ACTIVE'),
    ('Contoso', 'contact@contoso.example.test', NULL, 'ACTIVE'),
    ('Fabrikam', 'sales@fabrikam.example.test', 3, 'SUSPENDED');
```

## Entity: `<Entity>.java`
```java
@Entity
@Table(name = "<table>")
public class <Entity> {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 100)
    private String name;

    @Column(nullable = false, length = 100)
    private String email;

    private Integer rating;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 20)
    private SupplierStatus status;

    protected <Entity>() {
    }

    public <Entity>(String name, String email, Integer rating, SupplierStatus status) {
        // assign every field
    }

    // getter for id; getter + setter for every other field. No id setter. No Lombok.
}
```
Rules:
- An optional column has no `@Column` unless it needs a `length`.
- A required non-String column gets `@Column(nullable = false)`.
- A `boolean` field gets `@Column(nullable = false)`.

## Repository: `<Entity>Repository.java`
```java
public interface <Entity>Repository extends JpaRepository<<Entity>, Long> {

    boolean existsBy<Unique>(String <unique>);

```
Without a unique field, the interface body is empty.

## Request / Response: `<Entity>Request.java`, `<Entity>Response.java`
```java
public record <Entity>Request(
        @NotBlank
        @Size(max = 100)
        String name,

        @NotBlank
        @Email
        @Size(max = 100)
        String email,

        @Min(1)
        @Max(5)
        Integer rating,

        @NotNull
        SupplierStatus status
) {
}

public record <Entity>Response(
        Long id,
        String name,
        String email,
        Integer rating,
        SupplierStatus status
) {
}
```
Rules:
- One annotation per line, and a blank line between components.
- Default messages only, unless it is a `@Pattern`. A `@Pattern` gets `message = "must be ..."` in lowercase, without the field name.

## Service: `<Entity>Service.java`
```java
@Service
@Transactional(readOnly = true)
public class <Entity>Service {

    private final <Entity>Repository <entity>Repository;

    public <Entity>Service(<Entity>Repository <entity>Repository) {
        this.<entity>Repository = <entity>Repository;
    }

    public List<<Entity>Response> findAll() {
        return <entity>Repository.findAll(Sort.by("id")).stream()
                .map(<Entity>Mapper::toResponse)
                .toList();
    }

    public <Entity>Response findById(Long id) {
        return <Entity>Mapper.toResponse(get<Entity>(id));
    }

    @Transactional
    public <Entity>Response create(<Entity>Request request) {
        if (<entity>Repository.existsBy<Unique>(request.<unique>())) {
            throw <unique>AlreadyExists(request.<unique>());
        }
        <Entity> <entity> = <entity>Repository.save(<Entity>Mapper.toEntity(request));
        return <Entity>Mapper.toResponse(<entity>);
    }

    @Transactional
    public <Entity>Response update(Long id, <Entity>Request request) {
        <Entity> <entity> = get<Entity>(id);
        if (<entity>Repository.existsBy<Unique>AndIdNot(request.<unique>(), id)) {
            throw <unique>AlreadyExists(request.<unique>());
        }
        <Entity>Mapper.updateEntity(<entity>, request);
        return <Entity>Mapper.toResponse(<entity>Repository.save(<entity>));
    }

    @Transactional
    public void delete(Long id) {
        <entity>Repository.delete(get<Entity>(id));
    }

    private <Entity> get<Entity>(Long id) {
        return <entity>Repository.findById(id)
                .orElseThrow(() -> new NotFoundException("<Entity> with id " + id + " not found"));
    }

    private static ConflictException <unique>AlreadyExists(String <unique>) {
        return new ConflictException("<Entity> with <field label> " + <unique> + " already exists");
    }
}
```
- `<field label>` follows SKILL.md step 3: acronyms in capitals, other words in lowercase.
- With several unique fields, use one `if` and one `...AlreadyExists` helper per field, in field order.

## Clock (only for date rules relative to today)
If `backend/src/main/java/com/example/dealership/config/ClockConfig.java` does not exist, create it:
```java
package com.example.dealership.config;

import java.time.Clock;
import java.time.ZoneId;

import org.springframework.boot.autoconfigure.validation.ValidationConfigurationCustomizer;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class ClockConfig {

    @Bean
    public Clock clock() {
        return Clock.system(ZoneId.of("Europe/Warsaw"));
    }

    @Bean
    public ValidationConfigurationCustomizer clockProviderCustomizer(Clock clock) {
        return configuration -> configuration.clockProvider(() -> clock);
    }
}
```
Then:
- `@PastOrPresent` / `@FutureOrPresent` on the request use this clock.
- A service that needs "today" takes `Clock` in its constructor and calls `LocalDate.now(clock)`.

## Nested
Placeholders: `<Parent>`, `<parent>`, `<parent_table>`, `<parents>` (URL).

Migration:
```sql
CREATE TABLE <table> (
    id          BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    <parent>_id BIGINT       NOT NULL,
    name        VARCHAR(100) NOT NULL,
    CONSTRAINT fk_<table>_<parent> FOREIGN KEY (<parent>_id) REFERENCES <parent_table> (id)
);
```
Entity:
- First field after `id`: `@Column(name = "<parent>_id", nullable = false) private Long <parent>Id;`.
- The constructor takes `<parent>Id` first.
- `<parent>Id` has a getter and no setter.

Repository:
```java
List<<Entity>> findAllBy<Parent>Id(Long <parent>Id, Sort sort);

Optional<<Entity>> findByIdAnd<Parent>Id(Long id, Long <parent>Id);

boolean existsBy<Parent>IdAnd<Unique>(Long <parent>Id, String <unique>);

boolean existsBy<Parent>IdAnd<Unique>AndIdNot(Long <parent>Id, String <unique>, Long id);
```
Mapper:
- `toEntity(Long <parent>Id, <Entity>Request request)`.
- The response has `<parent>Id` right after `id`.

Service:
- Injects `<Parent>Repository` as the second constructor argument.
- Every public method takes `Long <parent>Id` first and starts with `require<Parent>(<parent>Id)`.
```java
public List<<Entity>Response> findAll(Long <parent>Id) {
    require<Parent>(<parent>Id);
    return <entity>Repository.findAllBy<Parent>Id(<parent>Id, Sort.by("id")).stream()
            .map(<Entity>Mapper::toResponse)
            .toList();
}

private void require<Parent>(Long <parent>Id) {
    if (!<parent>Repository.existsById(<parent>Id)) {
        throw new NotFoundException("<Parent> with id " + <parent>Id + " not found");
    }
}

private <Entity> get<Entity>(Long <parent>Id, Long id) {
    return <entity>Repository.findByIdAnd<Parent>Id(id, <parent>Id)
            .orElseThrow(() -> new NotFoundException("<Entity> with id " + id + " not found"));
}
```
Controller:
- `@RequestMapping("/api/<parents>/{<parent>Id}/<entities>")`.
- Every handler takes `@PathVariable Long <parent>Id` first.
- `Location` uses the same `fromCurrentRequest().path("/{id}")`.

Parent delete: change nothing, unless the integration test from [tests.md](tests.md) gets 500. In that case, the parent service becomes:
```java
@Transactional
public void delete(Long id) {
    <parent>Repository.delete(get<Parent>(id));
    <parent>Repository.flush();
}
```
